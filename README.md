# 1.ETL Ecommerce Pipeline
This project demonstrates an end-to-end ETL pipeline built to process real-world e-commerce sales data.
It simulates how a Data Engineer or BI Analyst would clean, enrich, and prepare data for generating business insights.
The pipeline is developed using Python (pandas), MySQL, and follows a modular structure that ensures scalability and clarity.

### 3. Dataset
The source data comes from the Online Retail II dataset, which contains transactions from a UK-based online store between 2009 and 2011.

- **File name**: `online_retail_II.xlsx`  
- **Source**: UCI Machine Learning Repository  
- **Description**: Includes details such as invoice number, product code, description, quantity, price, customer ID, country, and invoice date.  
- **Location**: Stored in `data/raw/`


### 4. ETL Process
The ETL process is designed to convert raw transactional data into structured and meaningful insights. It follows three key stages:

- Extract:
The data is extracted from the online_retail_II.xlsx file, located in data/raw/, using pandas. 
The raw data is loaded into memory for further processing.
• File name: online_retail_II.xlsx
• Source: Excel file (.xlsx)
• Tool used: Python (pandas)

- Transform:
The transformation process involves cleaning and enhancing the data:
    • Remove duplicates
    • Handle missing values
    • Convert date formats
    • Create new columns (e.g., TotalPrice, ProductCategory)
    • Normalize formats and validate data types
    • Location: data/processed/ (The resulting cleaned data is saved in CSV format in the data/processed/ folder.)

- Load:
The transformed data is loaded into a MySQL database for analysis:
• Database: MySQL
• Table name: cleaned_sales
• Columns: Invoice, StockCode, Description, Quantity, InvoiceDate, Price, CustomerID, Country, TotalPrice


### 5. Dependencies
This project requires several Python libraries to run properly. You can install all dependencies using the requirements.txt file provided in the project.

- Python version: 3.x
- Libraries:

To install the dependencies, use the following command:

### 7. How to Run the Project
To run the ETL pipeline and load the data into MySQL, follow these steps:

- 7.1. Clone the repository
Clone the repository to your local machine using Git:
`git clone https://github.com/yourusername/ETL_Ecommerce_Pipeline.git`

- 7.2. Install dependencies
Ensure that all required libraries are installed by running the following command in your terminal:
`pip install -r requirements.txt`

- 7.3. Set up MySQL Database
• Make sure you have MySQL installed and running on your machine.
• Create a new database called etl_ecommerce_pipeline (or another name if you prefer).
Run the SQL script to create the cleaned_sales table:
`mysql -u username -p < create_cleaned_sales_table.sql`
• Use a MySQL client to verify that the table was created correctly with the specified columns.

- 7.4. Run the ETL pipeline
To run the pipeline and process the data, execute the following command:
`python main.py`

This will:
    • Extract the raw data from data/raw/online_retail_II.xlsx.
    • Transform the data by cleaning and creating new columns.
    • Load the cleaned data into the MySQL database.

- 7.5. Verify the data in MySQL: 
After running the ETL process, check the cleaned_sales table in your MySQL database to confirm that the data has been loaded successfully.
